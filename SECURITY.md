# Security

Report a vulnerability through GitHub private vulnerability reporting:

https://github.com/ViateAI/viate/security/advisories/new

Do not open a public issue for a vulnerability.

This process stores upstream API keys and admin sessions, and it moves customer balances.

A report should include a version or commit, the affected route, and a reproduction. Fixes go to the latest commit on `main`. There is no older supported release line yet.
